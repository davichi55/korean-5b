# Korean 5B 단어장

Sogang Korean 5B study site, for classmates. Rebuilt from scratch on 2026-10-15 from the class handouts
(기말 복습 단어 확인, 5B 비디오 기말 복습 단어 목록, 5B 문법) and the textbook contents page:

- **단어**: 784 words in 8 chapters, split like the book: 읽기 I · 말하기 I · 읽기 II · 비디오 (★ = starred on the handout)
- **문법·표현**: the 37 grammar points of the contents page, with explanations, examples, practice and a quiz
- **바꿔 쓰기**: word swap questions, grammar sentence tiles and adverb practice
- **기말시험 연습**: a mock final in the class practice-sheet format

Languages: English · 简体中文 · 繁體中文 · ไทย · Русский · Tiếng Việt. Pick yours once; your phone remembers it.

Meanings, example sentences and practice questions were written with AI help — ask a teacher if something looks off.

This folder is generated: the source is `new-site/` in the parent project (`node src/build.js`, then `build_swap.js`,
`build_exam.js`, `build_grammar.js`).
