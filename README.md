# Korean 5B 단어장

Sogang Korean 5B study site, for classmates: vocabulary (8 chapters, video + 읽기·말하기 words), 바꿔 쓰기 practice
(words, grammar tiles, adverbs), 문법·표현 explanations and a mock final exam, in
English · 简体中文 · 繁體中文 · ไทย · Русский · Tiếng Việt. Pick your language once; it is remembered on your phone.

Translations, practice sentences and exam questions were written with AI help — ask a teacher if something looks off.

This folder is generated: edit `web/src/` in the parent project and run `node build.js`, `node build_swap.js`,
`node build_exam.js` and `node build_grammar.js`.
